# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! 👋

This project is a simple and responsive **personal portfolio website** created using **HTML and basic CSS**. It showcases my introduction, skills, projects, and contact information in a clean and beginner-friendly layout.

## 🚀 Technologies Used

* HTML5
* CSS3

## 📌 Features

* Personal introduction
* About Me section
* Skills section
* Projects section
* Contact section
* Basic responsive layout
* Clean and simple UI
